# Retail Intelligence – Retail Management System

## About the Project
Retail Intelligence is a Python-based Retail Management System designed to manage inventory, record sales, generate reports, and provide machine learning-based predictions.

## Features
- Dashboard Overview
- Inventory Management
- Record a Sale
- Sales and Reports
- ML Predictions
- Model Information

## Technologies Used
- Python
- Streamlit
- Pandas
- SQLite
- Scikit-learn
- Joblib
- Matplotlib

## Project Structure
```text
Retail_Management_Dashboard/
│
├── app.py

├── logistic_model.pkl
├── random_forest_model.zip
└── README.md
```

## Installation and Setup

1. Clone the repository:
```bash
git clone https://github.com/anishxai8486/repo.git
```

2. Open the project folder:
```bash
cd repo
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
streamlit run app.py
```
